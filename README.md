The first time you copy this template as a project folder, make sure to go to `~/Desktop/Google Drive/brendeneum/.` and make a subfolder with the name of the project.

Inside that, click and drag the `data`, `admin`, `docs`, `experiments`, and `presentations` folders.

Then, make a symlink for each (right click -> Services -> Make Symbolic Link), and drag those symlinks back to the main project folder.



Next, go to Overleaf, make your new paper. Then sync that to GitHub as it's own repo, and clone that repo to this project folder as "paper". Then copy the contents of the template's paper folder into that sub-repo.
